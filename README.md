# Мессенджер 

## О проекте

Мессенджер с клиент-серверной архитектурой, поддерживающий:
- Личные сообщения между пользователями
- Групповые чаты (комнаты)
- Регистрацию и аутентификацию (JWT)
- Шифрование трафика (TLS)
- Хранение истории сообщений (SQLite)
- Логирование всех действий

**Язык реализации:** Go 
## Обоснование выбора Go
Критерий	                   Go	                             C/C++
Многопоточность	      Горутины (легковесные потоки)	pthread, сложная синхронизация
WebSocket	          Готовые библиотеки	        Нужно писать с нуля или подключать libwebsocket
Управление памятью	  Сборщик мусора	            Ручное (new/delete), риск утечек

## Технологии

|      Компонент      |         Технология          |

## Быстрый старт

### Требования

- Go 1.21 или выше
- OpenSSL (для генерации сертификатов)

### Установка и запуск

#### 1. Клонирование репозитория
```bash
git clone https://github.com/Montorz/messenger
cd messenger
```

#### 2. Установка зависимостей
```bash
go mod download
```

#### 3. Генерация SSL сертификатов
```bash
openssl req -x509 -newkey rsa:4096 -keyout server.key -out server.crt -days 365 -nodes -subj "/CN=localhost"
```

#### 4. Запуск сервера
```bash
go run cmd/server/main.go
Сервер запустится на https://localhost:8443
```

#### 5. Запуск клиента
```bash
go run cmd/client/main.go
```

### Команды клиента
Команда	            Описание	                            Пример
просто текст	    Отправить сообщение в текущую комнату	Всем привет!
/create <название>	Создать новую комнату и войти в неё	    /create gamers
/join <название>	Войти в существующую комнату	        /join gamers
/leave <название>	Выйти из комнаты	                    /leave gamers
/rooms	            Показать список всех доступных комнат	/rooms
/room	            Показать текущую комнату	            /room
/msg <user> <текст>	Отправить личное сообщение	            /msg egor Привет!
/history <user>	    Показать историю переписки	            /history egor
/users	            Показать список онлайн пользователей	/users
/exit	            Выйти из программы	                    /exit

    README.md

### Сетевой режим
Для работы между разными компьютерами в локальной сети:

На серверной машине запусти сервер (IP автоматически определится)
На клиентской машине при запуске укажи IP сервера:
```bash
Введите IP адрес сервера (Enter для localhost): 192.168.1.100
Шифрование (TLS)
Все соединения защищены TLS 1.2/1.3:
```

### Шифрование (TLS)
Все соединения защищены TLS 1.2/1.3:
API: https://localhost:8443 
WebSocket: wss://localhost:8443/ws

### Проверка в Wireshark
Запусти Wireshark
Примени фильтр: tls.port == 8443
Отправь сообщение через клиент
В Wireshark виден только TLS handshake и зашифрованные данные

### Обработка сигналов (UNIX)
Сигнал	        Действие
SIGINT (Ctrl+C)	Завершение работы
SIGTERM	        Завершение работы
SIGHUP	        Перечитывание конфигурации без остановки

#### Отправить сигнал:
```bash
kill -HUP <PID>
```
